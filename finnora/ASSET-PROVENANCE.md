# FINNORA 3.0 asset provenance

The twelve bundled design SVGs are original demo artwork authored for this project. They are sample designs, not licensed manufacturer print files.

assets/images/gingerbread-cta.webp was generated with the built-in image generation tool and optimized locally with PHP GD. Prompt direction: a front-facing cheerful golden-brown baked-cookie head and upper torso, realistic biscuit texture, toasted edges, white icing, red bow tie, both hands resting at the same horizontal edge, transparent background, no text or extra objects. The original generation is retained in the local Codex generated_images directory. No external image API or customer photo was used.

Product previews are schematic compositions. They do not establish print area, manufacturing quality, or fulfillment integration. Customer uploads are never sent to an image generation service by this theme.
